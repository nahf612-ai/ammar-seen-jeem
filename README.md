# عمار سين جيم — أونلاين

نسخة متعددة الأجهزة من اللعبة، فيها 1310 أسئلة وفئات ولوحة 6×3 ومقدم يوزع النقاط.

## التشغيل محلياً
1. ثبّت Node.js إصدار 20 أو أحدث.
2. افتح مجلد المشروع ثم نفّذ `npm install` و `npm start`.
3. افتح `http://localhost:3000` من الكمبيوتر، أو رابط الخادم بعد نشره.

## النشر
ارفع مجلد المشروع كاملاً إلى استضافة Node.js تدعم اتصالات WebSocket (مثل Render أو Railway). استخدم `npm install` للبناء و`npm start` للتشغيل. لا تحتاج إلى متغيرات بيئة إلزامية؛ المنصة تضبط PORT غالباً.

## اللعب
المقدم ينشئ غرفة، يرسل رابط الموقع ورمز الغرفة للاعبين، ثم يختار ست فئات قبل اللعب. الفريقان ينضمان من هاتفين، والمقدم يختار مربع السؤال ويكشف الإجابة ويمنح النقاط. بعد 18 سؤالاً يظهر الفائز.

## ملاحظات
- الأسئلة تشمل معلومات عامة وعواصم ورياضيات، ومعظم الزيادة أسئلة حسابية مولدة.
- الغرف والنتائج محفوظة في ذاكرة الخادم فقط، وتُفقد عند إعادة تشغيله أو خروج المقدم.
- يعمل المشروع على نسخة خادم واحدة؛ لا يدعم التوسع الأفقي دون إضافة مخزن جلسات مشترك.
- هذه النسخة ليست منشورة على عنوان إنترنت عام حتى ترفعها إلى الاستضافة.
